# 骨折影像学评估基础

> 本项目**整理摘要**。本文说明骨折影像评估的一般原则，
> 不能替代影像科医师的阅片与报告。

## 1 基本检查：X 线平片

X 线平片是骨折影像评估的**首选与基础**检查。规范的做法包括：

- **至少两个互相垂直的体位**（通常是正位与侧位）。
  单一体位会遗漏与投照方向平行的骨折线
- **包含骨折部位上下两个关节**，用于判断力线与是否存在合并损伤
- **必要时加拍特殊体位**：如踝穴位（mortise 位）、髋关节轴位、
  斜位片等，用于显示特定结构

### 阅片时应系统观察的内容

1. **骨折是否存在**：骨皮质连续性、骨小梁走行
2. **骨折线走行**：横行、斜行、螺旋、粉碎
3. **移位与成角**：短缩、分离、侧方移位、成角、旋转
4. **关节面**：是否累及、有无塌陷或台阶
5. **力线**：整体对线
6. **软组织**：肿胀、气影（提示开放性损伤或产气菌感染）
7. **骨骼质量**：骨密度、是否有骨质破坏（需警惕病理性骨折）

**系统化阅片的意义**：骨折漏诊常发生在"找到一处骨折后就停止观察"。
多发伤患者、以及同一肢体的多处损伤，需要按部位逐一系统检查。

## 2 容易漏诊的骨折

部分骨折在初次 X 线检查中容易漏诊，需要特别留意：

| 部位/类型 | 漏诊原因 |
|---|---|
| 股骨颈骨折（无移位型） | 骨小梁嵌插，骨折线不明显 |
| 舟骨骨折 | 腕骨重叠，早期骨折线可阴性 |
| 胫骨平台塌陷（III 型） | 塌陷位于平台中央，正位片不易显示 |
| 股骨远端 Hoffa 骨折 | 冠状面骨折块与股骨髁重叠，正位片遮挡 |
| 应力性骨折 | 早期仅有骨膜反应，X 线可阴性 |
| 儿童骨骺损伤 | 骨骺线未闭合，需与骨折线鉴别 |

**处理原则**：临床高度怀疑而 X 线阴性时，应进一步检查
（CT、MRI 或短期复查），而不是直接排除骨折。

## 3 CT

CT 在骨折评估中的价值集中在**骨性结构的细节**：

- **关节内骨折**：判断关节面骨折块数量、位置、塌陷范围与深度
- **复杂骨折的分型**：如胫骨平台、股骨远端、跟骨、骨盆
- **隐匿骨折的检出**：平片阴性但临床怀疑
- **术前规划**：手术入路、内固定选择、螺钉方向
- **三维重建**：直观显示骨折块的空间关系

**CT 对软组织与韧带的评估能力有限**。判断半月板、韧带损伤仍需 MRI。

## 4 MRI

MRI 的优势在于**软组织与骨髓**：

- **隐匿性骨折**：骨髓水肿在 MRI 上显示敏感，
  是 X 线与 CT 阴性时的重要补充（如髋部隐匿性骨折）
- **韧带与半月板损伤**：如膝关节、踝关节合并损伤
- **软骨损伤**
- **骨坏死**：如股骨颈骨折后股骨头缺血坏死的早期发现
- **感染与肿瘤**：鉴别病理性骨折

**局限**：检查时间长、费用高、对金属内固定物有兼容性要求，
不适合作为骨折的首选筛查手段。

## 5 超声

- 对**软组织**（肌腱、韧带、积液）评估有价值
- 可用于**儿童骨折**的部分场景（减少辐射）
- 可辅助评估骨折复位情况与神经血管结构
- **对骨性结构穿透力有限**，不能替代 X 线与 CT

## 6 检查选择的一般思路

| 临床场景 | 通常考虑 |
|---|---|
| 可疑骨折初筛 | X 线平片（两个体位） |
| X 线阴性但高度怀疑 | CT 或 MRI（按部位选择） |
| 关节内骨折 | X 线 + CT（常需三维重建） |
| 怀疑韧带/半月板损伤 | MRI |
| 怀疑隐匿性髋部骨折 | MRI |
| 术后复查骨愈合 | X 线为主，必要时 CT |

具体检查由临床医师根据病情开具，本文仅为一般性说明。

## 7 关于辐射的说明

CT 的辐射剂量高于 X 线平片。对**儿童与孕妇**，
检查选择需权衡获益与辐射风险，必要时优先考虑超声或 MRI。
这一权衡由临床医师与影像科医师共同判断。
