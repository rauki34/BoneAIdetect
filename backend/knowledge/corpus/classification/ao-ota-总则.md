# AO/OTA 骨折分型总则

> 本文为**本项目整理摘要**，依据公开的 AO/OTA 骨折与脱位分型纲要（AO Foundation）
> 的分型框架编写，用于说明该分型的编码结构。**不是原文翻译，也不能替代原分型纲要。**
> 临床应用请查阅 AO/OTA 分型纲要原文或本院采用的版本。

## 1 设计目的

AO/OTA 分型把全身骨骼按解剖部位编号，再用字母与数字描述骨折形态。
它要回答三个问题：

1. **骨折在哪个部位**（解剖编号）
2. **是否累及关节面**（A / B / C）
3. **骨折的严重程度与形态**（进一步分组）

分型的意义不在于给骨折贴标签，而在于它是**治疗决策与预后判断的共同语言**：
同一分型的骨折，其手术入路、内固定选择、负重时机与随访计划有可预期的共性。

## 2 解剖编号

全身骨骼被划分为若干区域，每一主要长骨再分为三段：

| 部位 | 编号 |
|---|---|
| 肱骨 | 1 |
| 尺桡骨 | 2 |
| 股骨 | 3 |
| 胫腓骨 | 4 |
| 脊柱 | 5 |
| 骨盆 | 6 |
| 手部 | 7 |
| 足部 | 8 |
| 其他 | 9 |

长骨的三段划分：**近端（1）、骨干（2）、远端（3）**。

因此"33"表示股骨远端，"41"表示胫骨近端，"23"表示桡骨/尺骨远端（前臂远端）。
两个数字的组合即"骨 + 段"，这是 AO/OTA 编码的前两位。

## 3 关节面累及程度：A / B / C

对长骨两端的分型，第三个字符表示关节面是否受累，这是分型中**最具临床意义**的一位：

| 类型 | 含义 | 说明 |
|---|---|---|
| **A** | 关节外骨折 | 骨折线不进入关节面。治疗重点在力线与长度 |
| **B** | 部分关节内骨折 | 骨折线进入关节面，但**部分**关节面仍与骨干相连 |
| **C** | 完全关节内骨折 | 关节面完全与骨干分离，关节面与干骺端均受累 |

**为什么这条最重要**：关节面是否累及，直接决定是否需要解剖复位。
关节内骨折若复位不良，关节面不平整会导致创伤性关节炎；
关节外骨折则更关注力线、长度与旋转的恢复。

## 4 进一步分组

在 A / B / C 之后，分型继续细分：

- **A 型**按骨折线数量与位置分 A1 / A2 / A3（逐步复杂）
- **B 型**按劈裂与压缩的方向组合分 B1 / B2 / B3
- **C 型**按关节面与干骺端的粉碎程度分 C1 / C2 / C3

通常约定：**数字越大，骨折越复杂、越粉碎**。
例如"33-C3"表示股骨远端完全关节内骨折且粉碎程度最高的一类。

## 5 完整编码示例

以"股骨远端完全关节内骨折，关节面与干骺端均粉碎"为例：

```
3  3  -  C  3
│  │     │  └─ 组：粉碎程度最高
│  │     └──── 型：完全关节内
│  └────────── 段：远端
└───────────── 骨：股骨
```

读作 **AO/OTA 33-C3**。

## 6 使用分型时的注意点

1. **分型依赖影像质量**。关节内骨折的分型在 X 线平片上容易低估，
   通常需要 CT 才能准确判断关节面骨折块的数量与移位方向。
2. **分型与治疗方案不是一一对应的**。同一分型在不同年龄、骨质条件、
   软组织状态下处理方式可能不同；分型是决策的输入之一，不是决策本身。
3. **观察者间一致性有限**。部分部位（如肱骨近端）的分型在不同医师之间
   一致性偏低，这是分型系统本身已知的局限，也是后续出现三维 CT 辅助分型
   研究的原因。
4. **记录时写全编码**。只写"关节内骨折"会丢失分型中关于粉碎程度的信息，
   影响后续随访对照。

## 7 与其他分型系统的关系

AO/OTA 是一套**通用框架**，很多部位同时存在专用的经典分型：

| 部位 | 常用专用分型 | 与 AO/OTA 的关系 |
|---|---|---|
| 股骨颈 | Garden 分型 | 侧重股骨头血供与移位程度 |
| 胫骨平台 | Schatzker 分型 | 侧重骨折形态与手术入路 |
| 肱骨近端 | Neer 分型 | 侧重骨折块数量 |
| 踝关节 | Danis-Weber、Lauge-Hansen | 分别侧重腓骨骨折高度与受伤机制 |
| 桡骨远端 | Fernandez、AO 分型 | 侧重受伤机制 |
| 开放性骨折 | Gustilo-Anderson | 补充软组织损伤程度，与骨分型并用 |

实际病历中常同时记录 AO/OTA 编码与部位专用分型，两者互为补充：
AO/OTA 便于跨部位统计与交流，专用分型更贴近该部位的临床决策习惯。
